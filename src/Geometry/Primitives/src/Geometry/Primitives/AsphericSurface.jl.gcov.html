      17              :     AsphericSurface{T,N,Q,M} <: ParametricSurface{T,N}
      18              : 
      19              : Surface incorporating an aspheric polynomial - radius, conic and aspherics are defined relative to absolute semi-diameter,.
      20              : `T` is the datatype, `N` is the dimensionality, `Q` is the number of aspheric terms, and `M` is the type of aspheric polynomial. 
      21              : 
      22              : 
      23              : ```julia
      24              : AsphericSurface(semidiameter; radius, conic, aspherics=nothing, normradius = semidiameter)
      25              : ```
      26              : 
      27              : The surface is centered at the origin and treated as being the cap of an infinite cylinder, thus creating a true half-space.
      28              : Outside of `0 <= ρ <= 1` the height of the surface is not necessarily well defined, so NaN may be returned.
      29              : 
      30              : `aspherics`  aspherics should be vectors containing tuples of the form (i, v) where i is the polynomial power of the aspheric term.
      31              : An empty vector is not permitted. Use `nothing` instead.
      32              : 
      33              : The sag is defined by the equation
      34              : 
      35              : ```math
      36              : z(r,\\phi) = \\frac{cr^2}{1 + \\sqrt{1 - (1+k)c^2r^2}} + \\sum_{i}^{Q}\\alpha_ir^{i}
      37              : ```
      38              : 
      39              : where ``r`` is the radial distance in lens units (not normalized), ``c = \\frac{1}{\\texttt{radius}}``, and ``k = \\texttt{conic}``.
      40              : The aspheric coefficients ``\\alpha_i`` therefore have units of length``^{1-i}``, the same convention as Zemax's even and odd
      41              : asphere surfaces. `normradius` is stored but not used to compute the sag.
      42              : 
      43              : The function checks if the aspheric terms are missing, even, odd or both and uses an efficient polynomial evaluation strategy.
